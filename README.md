────────────────────────────────────────

📦 એપ કયા પ્રકારનો ડેટા સંગ્રહ કરે છે?

📱 Local Storage
TA entries, duty records, generated PDF history

☁️ Firebase Auth
Registered gmail- google signup, mobile number, login session, registration form data

────────────────────────────────────────

🔄 ડેટા ક્યારે ડીલીટ થાય?

🗑️ App Uninstall કરો  [Automatic]
Local storage નો બધો TA data તરત જ delete થઈ જાય છે —
TA entries, Duty records, PDF history — કોઈ manual request જરૂરી નથી.

📲 Firebase Account Data  [Request જરૂરી]
Firebase Authentication માં store google sign up અને registration data
delete કરવા Help & Support નો સંપર્ક કરવો પડે.

🔁 ફરી Login કરો
App reinstall કર્યા પછી ફરીથી login કરી શકો છો.
TA entries and Patrol book fresh start — નવેસરથી entry કરી શકો છો.

────────────────────────────────────────

✅ App uninstall = TA data automatic delete — કોઈ request વગર.
✅ Firebase account delete = Support contact કરો — 30 days માં remove.
✅ Re-registration = ગમે ત્યારે ફરથી account બનાવી શકો.

────────────────────────────────────────

📌 નોંધ: Prasthan app account delete કર્યા વિના
કારણ કે TA entries and Patrol book entries device ના local storage માં save છે — app delete = data delete.

User Google Drive Backup હોય તો data delete કરી પુન:સ્થાપન કરો એટલે ગુગલ ડ્રાઈવમાંથી પણ ડેટા નિકળી જશે.
